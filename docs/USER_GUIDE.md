# Guía del estudiante

1. Abra la página principal y elija Evaluación docente.
2. Ingrese el código institucional.
3. Revise grado, periodo y docentes pendientes.
4. Seleccione un docente y responda todos los criterios.
5. Agregue un comentario opcional sin nombres ni datos personales.
6. Envíe la evaluación. El docente pasará a Evaluaciones realizadas.

La sesión vence después de dos horas. Una evaluación enviada no puede repetirse.
